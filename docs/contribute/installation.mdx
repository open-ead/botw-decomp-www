Follow these steps to set up the project.

## Set up dependencies

You'll need to install the following programming tools:

* Ninja
* CMake 3.30+
* ccache (to speed up builds)
* xdelta3 (only needed if you have a version of BOTW newer than 1.5.0)
* Clang (not for compiling BotW code, but for Clang-based tools such as `clang-format`)

:::info
Ubuntu users can install those dependencies by running:

```shell
sudo apt install ninja-build cmake ccache xdelta3 clang libssl-dev pkg-config
```
:::

Additionally, you'll also need:

* [UV](https://docs.astral.sh/uv/getting-started/installation/) for running python tools.

## Dump the executable from a Switch

Next, you'll need to acquire the **original 1.5.0, 1.6.0, or latest `main` NSO executable**.

* To dump it from a Switch, follow [the instructions on the wiki](https://zeldamods.org/wiki/Help:Dumping_games#Dumping_binaries_.28executable_files.29).
* You do not need to dump the entire game (RomFS + ExeFS + DLC). Just dumping the ExeFS is sufficient (or even just the `main` executable).
* The compressed 1.5.0 NSO has the following SHA256 hash: `898dc199301f7c419be5144bb5cb27e2fc346e22b27345ba3fb40c0060c2baf8`

## Set up the repo

:::info
`uv` is required for running the Python scripts for the project. However, you do not
need to invoke it yourself. As long as the `uv` executable is in `PATH`, running
the script directly will invoke `uv` for you using a shebang directive.

i.e. Instead of `python3 tools/setup.py` or `uv run tools/setup.py`, you should run just `tools/setup.py`.

`uv` also will manage the virtual environment created at `tools/.venv` and automatically
keep the Python dependencies updated. For the most part, you will not feel its existence.
:::

1. Clone this repository. If you are using WSL, please clone the repo *inside* WSL, *not* on the Windows side (for performance reasons).
   If you plan to contribute, create a fork on GitHub and clone your fork instead (replace `zeldaret` with your username).

  ```shell
  git clone git@github.com:zeldaret/botw
  cd botw
  ```

2. Run `git submodule update --init --recursive`

3. Run `tools/setup.py [path to the dumped 'main' file]`
    * This will:
        * Convert the dumped executable to ELF and store it in the repo locally.
        * Set up [Clang 4.0.1](https://releases.llvm.org/download.html#4.0.1) as the toolchain for compiling the project,
          by downloading it from the official LLVM website.
        * Create a CMake build directory `build/`.
        * Install companion tools from [Viking](https://github.com/open-ead/viking)
    * If something goes wrong, follow the instructions given to you by the script.

## Build

To start the build, just run

```shell
ninja -C build
```

Note that Ninja will perform a multithreaded build by default. There is no need to pass `-j` manually.

After the build completes, run the checker to make sure everything built correctly:

```shell
tools/check
```

:::success OK?
If you see an `OK` message, congrats! You have successfully set up the project.
:::
